## 📖 About This Tracker

This spreadsheet documents the internship on a **daily basis**, organized by week. For each working day, it captures:

- **Day & Date** — calendar day and weekday
- **Type** — Full Day / Half Day / Leave / Off
- **Task Assigned** — what was scheduled for the day
- **Task Performed** — the actual work/session completed
- **Learnings (Technical)** — key concepts, protocols, and tools covered
- **Skills Developed (Soft Skills)** — professional/interpersonal skills built that day

## 🗂️ Structure

The tracker spans **5 weeks**, with Sundays marked as off days:

- **Week 1** — Networking fundamentals: LAN/WAN/MAN/PAN classification, network devices, IPv4 basics, OSI/TCP-IP models, endpoint security
- **Week 2** — Cybersecurity core: CIA triad, threat types & actors, MITRE ATT&CK Framework, server room walkthrough, switches/routers/firewalls/VLANs/SSH, network protocols (TCP/IP, DNS, DHCP, TLS/SSL, VPN types), ransomware, antivirus, EDR/XDR/MDR, IOA & IOC
- **Week 3** — CCNA focus: DHCP, STP, SD-WAN, 2FA, dynamic routing (OSPF, BGP, HSRP/GLBP), ACLs, NAT, hashing & salting
- **Weeks 4–5** — Continued CCNA practice and project work (in progress)
